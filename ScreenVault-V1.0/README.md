# ScreenVault V1.0

A cybersecurity + entertainment technology MVP.

Run:
```bash
cd app
npm install
npm start
```
Open http://localhost:3000

Demo:
actor@screenvault.local / ActorDemo123!
casting@screenvault.local / CastingDemo123!

Do not use real sensitive media or credentials. This is a portfolio/learning build, not production infrastructure.

Roadmap after V1.0: PostgreSQL, private object storage, MFA/passkeys, rate limiting, malware scanning, stronger provenance, organization/team controls, integrations, and real user validation.
